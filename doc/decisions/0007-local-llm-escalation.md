# ADR 0007：Local LLM 作為低頻異常升級決策層

## 狀態

Planned — 2026-08-09，尚未進入目前 Phase 0 實作範圍。

## 決策

未來可加入 Local LLM 作為低頻高階決策層。常規操作由確定性規則與可驗證狀態機完成；只有在無合法動作、同一行為重複失敗或必要觀測互相矛盾時，才可將裁切後的結構化狀態交給 LLM 介入判斷。

LLM 輸出必須符合白名單 schema，只能選擇高階意圖、要求重新觀測或停止。它不得直接輸出滑鼠座標、鍵盤序列或逐步控制事件，也不得繞過信心、資料新鮮度、前景視窗、使用者授權與緊急停止 Gate。

## 效能與失敗邊界

- 模型推理不得阻塞當前動作確認、緊急停止或快速安全規則。
- 等待、逾時、格式錯誤或低信心回覆一律 fail closed。
- 呼叫原因、輸入摘要、延遲、輸出與採納結果須寫入本機診斷紀錄。
- 正式啟用前須以固定案例比較無 LLM 基準，證明它降低失敗率且未增加不安全操作。

初始候選模型為使用者已有的 Qwen3-8B Q4_K_M GGUF；模型、推理引擎與硬體適配仍需另行驗證，不在本決策中宣稱支援。
