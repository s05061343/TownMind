# ADR 0006：唯讀解析 AOE2 DE 靜態遊戲資料

## 狀態

Accepted — 2026-08-09。

## 決策

TownMind 可唯讀解析使用者指定的 AOE2 DE 安裝目錄，建立版本化的本機遊戲知識庫，內容可包含單位、建築、科技、成本、訓練與建造時間、前置條件、升級鏈、文明可用性及 AI 常數。

- 不修改、替換或重新封裝遊戲檔案。
- 匯入器以檔案雜湊與解析器版本識別快取；遊戲更新後舊快取不得靜默沿用。
- 解析失敗、版本未知或欄位不完整時標示 unavailable，不以預設值冒充遊戲資料。
- 解析結果只提供靜態規則知識，不代表真人席位的即時資源、單位、地圖、視野或命令狀態。
- 新增的解析欄位與映射必須有固定樣本及自動回歸測試。

## 後果

規劃器不再硬編碼可由遊戲資料可靠取得的成本與前置條件。即時閉環仍需外部觀測、前後驗證及非侵入式控制後端，不能用靜態資料取代。
