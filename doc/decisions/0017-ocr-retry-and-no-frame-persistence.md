# ADR 0017：OCR 失敗重試、人口成對確認與不保存遊戲畫面

## 狀態

Accepted — 2026-08-13。

## 決策

AgePilot 不提供 Live Trace 或遊戲畫面保存功能。程式只在記憶體中擷取畫面供 OCR 與本機 VLM 使用；一般診斷 JSONL 可記錄 OCR 原始文字、信心、解析結果、拒絕原因與自動操作事件，但不得寫入 Frame buffer 或遊戲截圖。

Adaptive OCR 只有在結果可解析且信心至少 70% 時立即快取。45%～70% 的可解析候選必須由連續兩次實際 OCR 得到相同值才可快取；ROI 像素改變會觸發新的辨識，但不會抹除相同值的時間候選。空白、解析失敗或低於 45% 的結果不得進入快取，下一個掃描週期必須重新辨識。強制更新或 ROI 像素改變後若辨識失敗，舊值不得冒充新觀測。

人口目前值與人口上限是單一 `(current, cap)` 觀測，必須一起確認或一起 unavailable。任一人口值不可用時，所有依賴人口的遊戲輸入 fail closed。剩餘人口不超過 2 時禁止生產村民並觸發 Minor 重規劃；木材足夠時才向 LLM 開放 `BuildHouse`。

人口 OCR 使用欄位專屬處理。優先接受原生 `/` 或全形斜線；若 PaddleOCR 將斜線辨識為 `1`、`I`、`l`、`|` 或完全漏掉分隔符，只能在拆分出唯一合法 `(current, cap)` 時修復。合法值要求沒有非單一零的前導零、`current <= cap`，且 Phase 0 支援的人口值與上限不超過 500；候選不唯一時維持 unavailable。非原生斜線結果會在記憶體中再以灰階、直方圖等化、Otsu 二值化及反相影像辨識，優先採用信心至少 45% 的原生分隔格式，且不得保存處理影像。仍需格式修復的結果即使模型信心很高，也會降為中等信心並要求兩次獨立 OCR 一致。

確定性 OCR、快取、Gate 與規劃事件必須有自動回歸測試。自動測試不代表遊戲端輸入已實機成功；房屋閉環仍需使用者操作實際對局，並以一般診斷事件及遊戲畫面上的結果驗收。

## 後果

- 辨識失敗不會被快取十秒；在預設設定下約 500ms 後重試。
- 中等信心人口可由重複辨識確認，不再出現目前人口可用但上限為 null。
- `5/5` 被辨識成 `515`、`5/100` 被辨識成 `5100` 等唯一可解格式可恢復；歧義字串仍 fail closed。
- AgePilot 不在磁碟建立 `traces` 目錄或保存動作前後畫面。
- 既有使用者檔案不由程式自動刪除。
