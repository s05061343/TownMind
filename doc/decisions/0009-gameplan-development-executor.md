# ADR 0009：GamePlan 自動發展執行器

## 狀態

Accepted — 2026-08-12。

2026-08-13：ADR 0011 將每次動作後的「強制重新規劃」限定為事件式 Minor 評估；只有父層失效證據才能向上提升重算範圍。

2026-08-13：ADR 0015 取代本決策中「模型直接選擇通用原子工具」與「不得重新啟用語意動作轉譯」的部分，改為具名動作註冊表加程式化結果驗證。避免第二策略來源的顧慮由 ADR 0015 維持：註冊表沒有自主決策權，LLM 仍是唯一決定「做什麼」的來源。本文所述的安全 Gate、Preview／Armed 與經濟範圍限制維持有效。

## 決策

自動操作只能消費 ADR 0008 的 Qwen3-VL `GamePlan.VisualDecision`，不得重新啟用 `AutomationPolicy`、`GenericEconomicPlanner` 或建築／科技轉譯規則作為第二策略來源。模型直接看畫面並選擇一個通用原子工具；程式只驗證工具、按鍵、座標、前景視窗、頻率及使用者授權。

- 依 ADR 0010，原子工具限 `Observe`、`Wait`、`LeftClick`、`RightClick`、`Drag`。世界目標使用 normalized 座標，命令面板使用校準格位；遊戲內禁止任何鍵碼或快捷鍵綁定。
- 一次只執行最高優先的一項動作，結果確認或逾時後回饋規劃器並重新評估 Minor；Major／Medium 預設保持不變。
- 預設 Preview。使用者可直接點 Overlay「啟用」授權本局；Dashboard 開關只控制全域開始熱鍵是否可 Armed。停止熱鍵、焦點／生命週期／觀測 Gate 失效立即停用。
- 建築與採集座標由 VLM 從完整 panorama 提出；程式負責視窗邊界、HUD 禁止區、前景與頻率 Gate。每次只送一個原子動作，下一張畫面確認結果前不得繼續。
- 靜態遊戲資料負責成本、前置條件與文明合法性；缺少可靠解析結果時不得由模型記憶補值。

## 目前限制

目前範圍為校正環境的陸地局經濟、經濟建築、經濟科技與升時代；不包含軍事、戰鬥與水圖經濟。VLM 低信心、逾時或連續失敗時停止，不由舊規則接管。
