# ADR 0004：使用者控制的 SendInput 自動操作

## 狀態

Accepted — 2026-08-09，由專案負責人明確變更 v2 原本的只讀範圍。

## 決策

AgePilot 可透過 Windows `SendInput` 對前景中的 AOE2 視窗送出使用者自訂鍵盤序列，範圍如下：

- 自動模式預設關閉；`Ctrl+F10` 開啟、`Ctrl+F12` 緊急關閉，熱鍵可自訂。
- 經濟模式只在可靠的食物與人口資料成立時，以使用者設定序列排入村民。
- 只要目前人口小於上限就可排入一名村民；例如 `4/5` 允許操作，`5/5` 才停止。
- 成功送出後，在人口尚未變化的 45 秒內不重複排村民，避免 OCR 尚未反映生產佇列時持續鎖住食物。
- 人口接近上限時不自動放置房屋，只在 Overlay 提示使用者處理座標。
- 軍事模式為獨立選項，循環執行非空白的軍營、靶場與馬廄序列。
- 只在遊戲為前景視窗、生命週期為 active 且 Vision health 達門檻時送出輸入。
- 不監看或攔截使用者鍵盤滑鼠；使用者以 Overlay 按鈕或停止熱鍵控制。

## 不變邊界

- 不注入遊戲程序、不讀取遊戲記憶體、不修改封包或遊戲檔案。
- 不自動選擇建築放置座標、不分析敵方隱藏資訊。
- 軍事按鍵預設留空，避免假設使用者的 AOE2 鍵位。
- Overlay 關閉或程式退出後不再送出任何輸入。
- 緊急停止熱鍵必須成功註冊才能從 Overlay 開啟自動模式；開啟熱鍵失敗時仍可用按鈕開啟，停止熱鍵維持有效。
- `SendInput` 失敗與權限層級問題只更新自動操作狀態，不得中斷 OCR 監看迴圈。

## 後果

此決策取代 v2 原本「不發送任何遊戲輸入」的產品限制。公開政策並未因此變成官方核准；是否使用及使用情境由專案負責人決定。所有序列與熱鍵保存在本機設定中。
