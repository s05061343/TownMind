# ADR 0004：真人席位的非侵入式外部自動操作

## 狀態

Accepted — 2026-08-09；2026-08-09 擴充為不綁定 `SendInput` 的非侵入式控制後端。

## 決策

AgePilot 服務真人玩家席位，不作為遊戲內自訂 AI 玩家。它可使用 `SendInput` 或其他不侵入、不破壞遊戲的外部控制後端，對前景中的 AOE2 視窗送出鍵盤、滑鼠或等價操作。任何後端都必須可由使用者啟用、立即停止、記錄結果並在觀測不可靠時 fail closed。

- 自動模式預設關閉；`Ctrl+F10` 開啟、`Ctrl+F12` 緊急關閉，熱鍵可自訂。
- 經濟模式只在可靠的食物與人口資料成立時，以使用者設定序列排入村民。
- 只要目前人口小於上限就可排入一名村民；例如 `4/5` 允許操作，`5/5` 才停止。
- 成功送出後，在人口尚未變化的 45 秒內不重複排村民，避免 OCR 尚未反映生產佇列時持續鎖住食物。
- 建築放置只有在選取狀態、目標區域合法性與後續結果均可驗證時才能自動執行；否則只提示使用者。
- 軍事模式為獨立選項，循環執行非空白的軍營、靶場與馬廄序列。
- 只在遊戲為前景視窗、生命週期為 active 且 Vision health 達門檻時送出輸入。
- 不監看或攔截使用者鍵盤滑鼠；使用者以 Overlay 按鈕或停止熱鍵控制。

## 不變邊界

- 不 Hook、不注入遊戲程序、不修改 DLL 或遊戲檔案、不攔截或竄改封包。
- 不使用可取得敵方隱藏資訊的來源。
- 可唯讀解析遊戲安裝目錄的靜態資料，但不得將其當成真人席位即時狀態。
- 不允許未驗證的任意座標；執行前後必須確認選取、目標與結果。
- 軍事按鍵預設留空，避免假設使用者的 AOE2 鍵位。
- Overlay 關閉或程式退出後不再送出任何輸入。
- 緊急停止熱鍵必須成功註冊才能從 Overlay 開啟自動模式；開啟熱鍵失敗時仍可用按鈕開啟，停止熱鍵維持有效。
- 任一控制後端失敗與權限層級問題只更新自動操作狀態，不得中斷觀測迴圈；後端失敗後不得自動改用風險更高的控制方式。

## 後果

此決策取代 v2 原本「不發送任何遊戲輸入」與「只允許 `SendInput` 鍵盤序列」的限制。公開政策並未因此變成官方核准；是否使用及使用情境由專案負責人決定。所有控制設定與操作紀錄保存在本機。
