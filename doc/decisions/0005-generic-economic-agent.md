# ADR 0005：通用經濟代理閉環

## 狀態

Accepted — 2026-08-09。

## 目標場景

- 通用文明，不使用文明加成或特殊單位作為前提。
- 通用標準陸地圖，從目前可見遊戲畫面尋找資源與建築候選位置。
- 通用流程：維持村民、21 人升封建、建立市場與鐵匠鋪、資源到位後升城堡。
- 使用者允許滑鼠移動、左右鍵、快捷鍵、選取與鏡頭相關操作。

## 閉環

> 2026-08-12：本節的 `Generic Economic Planner` live path 已由 ADR 0008 的統一 `GamePlan` 取代。第一個 LLM 垂直切片只顯示 HUD，不發送輸入；下列內容保留為未來 executor 的安全與確認基準。

```text
GDI 畫面 → HUD OCR + World Analyzer → Generic Economic Planner
        → Non-invasive Control Backend → Pending confirmation
        → 下一幀確認／逾時恢復
```

World Analyzer 可以用降採樣顏色群聚產生食物、木材、黃金、石頭與建築空地候選，但候選不得直接驅動操作。只有在目標分類、選取狀態、可操作性與跨幀一致性均達到該行為門檻時，才可將標準化座標交給控制後端；任何欄位未知、過期、矛盾或低信心時都必須停止該動作。

## 通用策略

1. 人口空間剩兩格且木材至少 25：選取閒置村民並建造房屋。
2. 黑暗時代人口至少 21、食物至少 500：升封建。
3. 封建時代依序建立市場與鐵匠鋪。
4. 前置建築已確認、食物 800、黃金 200：升城堡。
5. 非關鍵階段依資源目標，只把已確認的閒置村民派往已確認且可操作的可見資源；只有候選點時不得送出命令。
6. 村民生產維持獨立節流，不因策略動作停擺。

## 確認與恢復

- 房屋：人口上限增加才確認。
- 市場／鐵匠鋪：木材顯著下降作為目前的間接確認；45 秒未確認則允許重試。
- 升級時代：OCR 時代變更才確認；150 秒未確認則解除 pending。
- 所有操作都要求 AOE2 是前景視窗；`Ctrl+F12` 立即停用後續操作。
- 每次策略、確認、逾時與失敗寫入本機 JSONL。
- 同一常規行為重複失敗、必要觀測矛盾或規劃器無合法動作時，停止輸入；未來可將結構化狀態升級給 Local LLM 作低頻高階判斷，但 LLM 不得直接產生座標或輸入事件。

## 已知限制

目前世界辨識是通用啟發式，不是經過多地圖標註訓練的物件偵測模型。森林、黃金與食物候選可能因地形／光照誤判，因此現有候選定位不得視為可用的自動操作能力；市場與鐵匠鋪以資源變化間接確認也不足以證明建築類型與位置。正式啟用相應動作前，必須加入不同地圖、玩家顏色、文明建築外觀及戰爭迷霧狀態的標註樣本與自動回歸證據。
