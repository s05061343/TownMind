# ADR 0005：通用經濟代理閉環

## 狀態

Accepted — 2026-08-09。

## 目標場景

- 通用文明，不使用文明加成或特殊單位作為前提。
- 通用標準陸地圖，從目前可見遊戲畫面尋找資源與建築候選位置。
- 通用流程：維持村民、21 人升封建、建立市場與鐵匠鋪、資源到位後升城堡。
- 使用者允許滑鼠移動、左右鍵、快捷鍵、選取與鏡頭相關操作。

## 閉環

```text
GDI 畫面 → HUD OCR + World Analyzer → Generic Economic Planner
        → Keyboard/Mouse Executor → Pending confirmation
        → 下一幀確認／逾時恢復
```

World Analyzer 以降採樣顏色群聚產生食物、木材、黃金、石頭候選點，並以遊戲區域局部亮度與變異評分建築空地。座標均標準化為 0～1，再映射回目前遊戲視窗。

## 通用策略

1. 人口空間剩兩格且木材至少 25：選取閒置村民並建造房屋。
2. 黑暗時代人口至少 21、食物至少 500：升封建。
3. 封建時代依序建立市場與鐵匠鋪。
4. 前置建築已確認、食物 800、黃金 200：升城堡。
5. 非關鍵階段依資源目標，把閒置村民派往可見的食物、木材或黃金候選。
6. 村民生產維持獨立節流，不因策略動作停擺。

## 確認與恢復

- 房屋：人口上限增加才確認。
- 市場／鐵匠鋪：木材顯著下降作為目前的間接確認；45 秒未確認則允許重試。
- 升級時代：OCR 時代變更才確認；150 秒未確認則解除 pending。
- 所有操作都要求 AOE2 是前景視窗；`Ctrl+F12` 立即停用後續操作。
- 每次策略、確認、逾時與失敗寫入本機 JSONL。

## 已知限制

目前世界辨識是通用啟發式，不是經過多地圖標註訓練的物件偵測模型。森林、黃金與食物候選可能因地形／光照誤判；市場與鐵匠鋪仍以資源變化間接確認。正式宣稱跨地圖可靠前，必須加入不同地圖、玩家顏色、文明建築外觀及戰爭迷霧狀態的標註樣本。
