# ADR 0011：階層式、事件驅動的 LLM 發展規劃

## 狀態

Accepted — 2026-08-13。

## 決策

AgePilot 的長期策略目前固定為「穩定發展經濟並升至玩家指定時代」；玩家可在 Dashboard 選擇封建、城堡或帝王，預設城堡。Qwen3-VL 負責 Major、Medium、Minor 三層判斷及下一個純滑鼠原子動作：Major 表示目前升時代階段，Medium 表示達成方法，Minor 表示當下小目標。

每層保存 ID、目標、理由、可見證據、完成條件、失敗條件與狀態。初次規劃或玩家／時代目標改變可更新 Major；方法失效可更新 Medium；動作完成、失敗或等待到期只更新 Minor。模型若發現凍結父層失效，必須先請求提升 update scope；不得在低層回覆中直接改寫父層。程式以 merge 與 schema 驗證強制執行此邊界。

2026-08-13：凍結父層的強制邊界改由 ADR 0013 的範圍限定 schema 直接執行——回覆 JSON schema 依 `allowedUpdateScope` 動態產生，凍結層的欄位不會出現在 schema 裡，模型在結構上就無法輸出；不再依賴逐欄位相等比對來偵測「越級改寫」。

不再固定每 20 秒重建整份計畫。每個輸入送出後進入 pending；到達重新觀察時間才要求模型確認，確認完成前不得送出新輸入。`Wait`／`Observe` 到期、動作結果、時代改變、方法失效及玩家更改目標都是明確事件。視覺動作過期只使 Minor 重新評估，不刪除仍有效的 Major／Medium。

LLM 呼叫失敗時保留上一份有效父層，最早 10 秒後才重試原範圍，避免失敗狀態形成高頻規劃迴圈。

## 後果

- 小幅 HUD 變化不再推翻發展方向。
- 羊、果樹或野生動物耗盡時可只替換食物方法，不重新決定長期策略。
- 不可靠或不可見目標只能得到 `Observe`／`Wait`；未知值仍為 unavailable/null。
- 本決策取代 ADR 0008、0009 中扁平 `GamePlan`、固定期限造成整份重建及每個執行事件強制完整重規劃的部分。
